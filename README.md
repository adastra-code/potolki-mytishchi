# Потолки Мытищи — сайт компании по натяжным потолкам

Сайт компании, которая устанавливает натяжные потолки и профильные системы
в Мытищах и Московской области: лендинг и отдельная страница со всеми работами.

Контакты, рейтинг, отзывы и цены взяты из карточки организации на Яндекс.Картах:
[Натяжные потолки, Мытищи, ул. Борисовка, 12А](https://yandex.ru/maps/org/natyazhnyye_potolki/154986104579/).

Сайт: **https://adastra-code.github.io/potolki-mytishchi/**  
Репозиторий: **https://github.com/adastra-code/potolki-mytishchi**

## Запуск

Нужен Node.js 18+ (проверено на Node 24).

```bash
npm run dev
```

Сайт откроется на [http://localhost:4321](http://localhost:4321).
Сборка не нужна — можно просто открыть `index.html` в браузере.

## Структура

```
index.html        — лендинг
gallery.html      — все 69 работ с лайтбоксом
css/style.css     — общие стили, адаптив, анимации
css/gallery.css   — стили галереи и лайтбокса
js/main.js        — меню, калькулятор, формы, аккордеон, модальное окно
js/gallery.js     — галерея и просмотрщик фотографий
assets/img/       — 5 избранных фото для лендинга
assets/gallery/   — 69 фото: thumb/ и full/
server.mjs        — локальный статический сервер без зависимостей
package.json      — скрипты запуска
```

## Что на странице

- первый экран с формой заявки, рейтингом и ключевыми цифрами;
- каталог потолков и блок с ценами на профильные системы;
- интерактивный калькулятор: площадь, тип полотна, светильники, демонтаж;
- преимущества, избранные работы, этапы работы, отзывы с Яндекс.Карт;
- FAQ-аккордеон, контакты с картой и формой записи на замер;
- страница `gallery.html` — все 69 фотографий объектов с полноэкранным просмотром,
  стрелками и свайпами.

## Как поменять контент

- **Телефон, адрес, часы работы** — поиском по `+7 (991) 969-09-99`,
  `Борисовка` и `Круглосуточно` в `index.html`. Телефон также указан в JSON-LD
  в `<head>` (для поисковиков).
- **Цены на профили** — блок `.price-list` в `index.html`.
- **Калькулятор** — ставки в `js/main.js` (`PRICE_LIGHT`, `PRICE_DEMOLITION`,
  `MIN_ORDER`) и значения `value` у radio в `#calculator`.
- **Отзывы** — карточки `.review`; сейчас это цитаты с Яндекс.Карт.
- **Цвета и шрифт** — CSS-переменные в начале `css/style.css` (`--brass`, `--ink`, `--paper`).
- **Фото работ** — избранные фото на лендинге лежат в `assets/img/`, все 69 —
  в `assets/gallery/thumb/` (превью) и `assets/gallery/full/` (для лайтбокса).
  Фотографии используются с разрешения владельца. При замене сохраняйте имена
  файлов или обновляйте пути в `index.html` и `gallery.html`.

## Формы

Формы работают в демо-режиме: проверяют поля и показывают сообщение об успехе,
но никуда не отправляют данные. Для реальных заявок подключите обработчик
(API CRM, Telegram-бот, Formspree) в `js/main.js` — в месте, где стоит
`setTimeout(...)` после валидации.

## Публикация

Подойдёт GitHub Pages, Netlify, Vercel или обычный хостинг: достаточно загрузить
`index.html`, `gallery.html`, папки `css`, `js` и `assets`. Никаких сборок
и зависимостей нет. Сайт уже опубликован на GitHub Pages, обновление — обычный
`git push` в ветку `main`.

## Важно перед запуском

- Замените демонстрационный текст политики конфиденциальности на актуальный.
- Проверьте актуальность цен и обещаний (гарантия, сроки, рассрочка).
- Формы нужно подключить к реальной CRM или почте.
- Фотографии работ используются с разрешения владельца; при добавлении новых
  снимков убедитесь, что права на них также переданы вам.
